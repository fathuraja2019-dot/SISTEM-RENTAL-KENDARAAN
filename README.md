# SISTEM RENTAL KENDARAAN

## Deskripsi
Sistem Rental Kendaraan merupakan program sederhana berbasis Python yang dibuat untuk memenuhi tugas UTS mata kuliah Pemrograman Berorientasi Objek.

Program ini digunakan untuk mengelola penyewaan kendaraan, menampilkan daftar kendaraan, menghitung biaya rental, serta mengelola pengembalian kendaraan.

## Fitur Program
1. Menampilkan daftar kendaraan.
2. Menyewa kendaraan.
3. Menghitung biaya penyewaan.
4. Mengembalikan kendaraan.
5. Menampilkan jumlah kendaraan.

## Konsep OOP
- Class dan Object
- Constructor (__init__)
- Attribute dan Method
- Encapsulation
- Property dan Setter
- Class Method
- Static Method
